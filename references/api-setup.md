# 行情 API 开通与配置指引（安装后首次引导必做）

看板默认使用**本地模拟行情**（随机波动，仅演示）。要看真实 A 股现价，用户需要配置**自己的**行情数据源。执行本技能时，按以下顺序引导用户完成开通，不要跳步、不要替用户填写密钥。

## 第 1 步：说明现状

告诉用户三件事：

1. 当前「刷新现价」是模拟行情，按钮结果会标注"（模拟行情）"；
2. 看板支持两种真实数据源：**用户自有行情 API**（推荐，数据归属清晰）或**腾讯公开行情兜底脚本**（免开通，仅命令行使用）；
3. 所有配置只保存在用户本机浏览器（localStorage），不会上传。

## 第 2 步：引导用户选择行情数据源

看板首次打开会**自动弹出「行情设置」**。弹窗内置 3 个数据源：

1. **腾讯财经**（默认）：公开行情接口 `qt.gtimg.cn`，实时现价 + 三大指数，**免注册、无需 Key**，开箱即用；
2. **东方财富**：公开行情接口 `push2.eastmoney.com`（JSONP），**免注册、无需 Key**，可作备用源，两者数据略有差异但均可信；
3. **自有 API / 自建服务**：用户已有行情服务时选这项，填接口地址和 Key。

引导要点：

- 免费源零配置，默认即可用；用户想换源时点对应卡片，点保存即生效；
- 为什么不默认接入 Tushare Pro：其实时行情需 5000 积分（约 500 元/年），免费积分（120）只有日线数据；同花顺 iFinD 为机构付费产品，均不适合作为"免注册"入口；
- **自有 API** 场景：用户**使用自己的账号注册申请** Key，不要代填、不要索要；Key 只存在用户本机浏览器；
- 自有 API 地址为 GET 方式，看板随请求头 `X-API-Key: <key>` 发送；若用户的服务用别的鉴权头，需用户自行在服务端适配或加代理；
- **返回格式约定**：

```json
GET {接口地址}?codes=688301,300872

{
  "quotes": [
    { "code": "688301", "price": 17.35 },
    { "code": "300872", "price": 14.88 }
  ]
}
```

兼容字段名：返回数组的顶层键可以是 `quotes`、`data` 或直接就是数组。

配置路径：打开看板 → 右上角「行情设置」→ 填入 API 地址与 Key → 保存。保存后「刷新现价」即走用户 API；调用失败时看板会展示错误原因并保留手动改价兜底。

## 第 3 步：免开通的兜底方案（腾讯公开行情）

用户暂时没有行情服务时，可用 `scripts/fetch_quotes.py` 走腾讯公开行情接口（qt.gtimg.cn，无需注册与密钥）：

```bash
python3 scripts/fetch_quotes.py --codes 688301,300872
# 自有 API 方式：
python3 scripts/fetch_quotes.py --api "https://your-api.example.com/quote" --key "sk-xxxx" --codes 688301
# 环境变量方式：QUOTE_API_URL / QUOTE_API_KEY
```

输出 `{"quotes":[{"code":"...","price":...}]}`，与看板约定一致，可作为用户自建行情服务的现成参考实现。

## 第 4 步：建议反馈入口说明（技能发布者维护）

看板右上角内置「建议」按钮，点击弹出作者的微信二维码，用户扫码添加好友即可提交修改意见。

- 二维码图片已以 base64 形式**内嵌在模板中**，单文件离线可用，无需额外图床；
- 技能发布者如需更换为自己的二维码：用新图片替换模板 `templates/stock-dashboard.html` 中 `fbQr` 区域的 base64 图片数据即可；
- 未配置图片时弹窗显示占位提示，不影响其他功能。

## 安全红线

- 不要求、不记录、不转发用户的 API Key；Key 只存在用户本机。
- 不替用户决定数据服务商；推荐时至少给出两种选择。
- 持仓数据属于个人隐私，任何输出（报告、截图建议、分享文案）都不得包含用户真实持仓明细。
