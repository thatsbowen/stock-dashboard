# 打赏（微信收款码）配置说明

## 当前实现

打赏已改为**微信收款码**，二维码直接内嵌在页面里（base64 data URI，约 125KB），**无外部依赖、无需任何配置**：

- 弹出时机：用户添加完**至少 1 只真实持仓**后自动弹出（内置演示数据不触发）；
- 频率：**每月最多提醒一次**；用户点「取消，继续使用」后下次仍会按时提醒；
- 关闭：点「已经支持过了，不再提醒」或「以后不再提醒」后**永久不再弹**（本机记录，无法验证是否真的付款）；「行情设置 → 打赏提醒」里可随时关闭/恢复；
- 用户点「取消，继续使用」可正常退出弹窗，所有功能不受影响，看板完全免费。

## 更换收款码（技能作者用）

1. 用微信「收付款 → 二维码收款 → 设置金额 ¥5.25」生成带金额的收款码图片；
2. 把图片转成 base64：`base64 -w0 收款码.png`；
3. 替换 `templates/stock-dashboard.html` 里 `<img class="tip-qr" id="tipQr" src="data:image/png;base64,...">` 的 `src` 值；
4. 建议 PNG 宽度 ≤ 800px、体积 ≤ 200KB（页面以 225px 宽展示）。

## 历史说明

V1.1.4 及之前版本使用支付宝 SkillPay 商品打赏（merchantId 2088002146606003 / productId P0806000211890968），V1.1.5 起已整体移除 SkillPay 依赖，改为微信收款码方案。
